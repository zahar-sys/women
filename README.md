# Женская коллекция

Двухстраничная витрина женской одежды. Временное название: «Здесь может быть название вашего магазина».

## Открыть в VS Code

1. Распакуйте ZIP.
2. В VS Code выберите **File → Open Folder** и откройте папку **Alexcors**.
3. Откройте встроенный терминал (**Terminal → New Terminal**).
4. Запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 5500
```

5. Перейдите в браузере на http://localhost:5500.

Можно также воспользоваться расширением VS Code **Live Server** и выбрать **Open with Live Server** для `index.html`.

Установка npm-пакетов и сборка не нужны. Для полной работы поиска и обновления адреса открывайте сайт через локальный сервер, а не через `file://`.

## Структура

- `index.html` — главная страница с женской коллекцией и временным названием магазина.
- `catalog.html` — каталог: 12 карточек, 5 категорий.
- `styles.css` — цвета, типографика, оформление и адаптация под телефон.
- `catalog.js` — фильтры, поиск, счётчик, пустое состояние.
- `assets/` — исходные фотографии прежней версии и иконка сайта.

## Категории

- `dresses` — платья, 3 карточки.
- `knitwear` — трикотаж, 3 карточки.
- `outerwear` — верхняя одежда, 2 карточки.
- `trousers` — брюки, 2 карточки.
- `sets` — комплекты, 2 карточки.

## Как редактировать товар

В `catalog.html` найдите нужный `<article class="product">`.

- `data-category` определяет категорию.
- `data-search` содержит текст для поиска: название, цвет и категорию.
- `<h2>` — название товара.
- `.product-description` — цвет или краткое описание.
- `.product-link` ведёт в Telegram-канал магазина.

Чтобы добавить вещь, скопируйте одну карточку и поменяйте эти поля. Счётчик JavaScript рассчитывается автоматически. При добавлении категории создайте кнопку с новым `data-filter` и используйте это же значение в `data-category` товаров.

## Фотографии

Все фотографии сохранены в `assets/women/` и подключены локально. Для загрузки изображений интернет не нужен. Старые скриншоты сохранены в `assets/`, но страницы больше их не используют.

Источники демонстрационной подборки: & Other Stories (Endource), Marks & Spencer, John Lewis, Mango, Gina Bacconi, Gready Brilliant, Gina Tricot, Brooks Brothers, Mudo, H&M (Superbalist), Et Vous (Matalan). Подборка иллюстрирует оформление витрины и не подтверждает ассортимент магазина.

Чтобы заменить снимок, поменяйте `src` и `alt` у `<img class="collection-photo">` в нужной карточке. Можно указать локальный путь, например `assets/dress.jpg`. Кадрирование управляется `.collection-photo` в `styles.css`.

## Важные детали

- Названия и цвета составлены по демонстрационным фотографиям. Цены, размеры и наличие не указаны: сайт предлагает уточнять их в Telegram.
- Ссылка магазина: https://t.me/AlexKorsStore.
- Это витрина: оплаты, корзины, аккаунтов и серверной базы данных нет.
- В архиве нет паролей, токенов или зависимости от ChatGPT. Его можно размещать на любом статическом хостинге.
